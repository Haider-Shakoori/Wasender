# WhatsApp campaign roadmap

- Parts 1–3: domain, preparation, queue execution, throttling, retries, and controls.
- Part 4: secure Node dispatch, private media, persistent idempotency, acknowledgements, usage, and reconciliation.
- Part 5: essential tenant workflows and redacted platform operational UI, including status polling and canonical reconciliation controls.
- Part 6: completed resource-constrained release validation, critical security/concurrency/idempotency regression coverage, migration rollback/reapply checks, builds, and controlled-release runbook.

Batch 13 is complete through Part 6. The release recommendation is **ready with conditions** for a controlled rollout; see [the release runbook](whatsapp-campaign-release.md). Phase 2 remains deferred.

Batch 17 Part 1 adds the independent [WhatsApp message-template domain foundation](whatsapp-message-templates.md). Variables, media, messaging integration, and final template UI remain deferred to Parts 2–5.
