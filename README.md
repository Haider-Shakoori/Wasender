## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.

# Message templates

The tenant workspace includes a versioned WhatsApp message-template library with fictional previews, private draft media, categories and labels, campaign snapshot application, and transactional compose integration. Platform operators have read-only metadata and usage visibility. See `docs/whatsapp-message-templates.md` for workflow and current limitations.

# Automation workflows

The automation module is feature-complete for the initial manual-workflow release: tenant and platform pages, ordered workflow building, publishing/enabling, safe manual runs, execution monitoring/cancellation, frozen WhatsApp template sends, label/group changes, approved contact updates, and stop actions. See `docs/automation-workflows.md`.
## Shared inbox

Batch 19 Part 1 adds tenant/session/direct-address conversations, idempotent signed inbound synchronization, normalized contact resolution, outbound projections, unread counters, and paginated foundational JSON reads. Agent operations and the final inbox UI are deferred.

Batch 19 Part 2 adds tenant-safe assignment, status, priority, shared read state, internal notes and mentions, saved replies, labels, and agent activity APIs. The complete inbox UI remains deferred to Part 3.

Batch 19 is feature-complete with responsive tenant inbox and saved-reply pages, canonical agent replies, bounded timelines, operational controls, and read-only platform inbox visibility.

Batch 22 Part 1 adds tenant-safe, bounded analytics services and JSON endpoints for messaging, sessions, campaigns, templates, automations, inbox operations, usage, and privacy-safe platform reporting. Dashboards and exports remain deferred.
